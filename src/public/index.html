La operación del restaurante, conectada.

RestaurantHub es una API REST que recibe solicitudes HTTP, valida la información, consulta MySQL y responde en JSON. Esta demo muestra el módulo de autenticación conectado.

Formato de la API
Para una presentación precisa: en esta versión, el router principal activa autenticación. Los demás módulos se muestran como parte del proyecto, no como endpoints listos para usar.
Arquitectura

Una petición, cuatro pasos

Un ejemplo rápido de cómo una llamada atraviesa la API.

1El cliente envía HTTP y, si corresponde, JSON.
2Express encuentra la ruta y valida la solicitud.
3El controlador y el modelo trabajan con MySQL.
4La API devuelve el resultado en formato JSON.
